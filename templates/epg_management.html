EPG Source Types
  • Schedules Direct: Recommended for US/Canada — premium TV listings synced to the database
  • XMLTV Grabber: Recommended for local or custom XMLTV grabber scripts
  • XMLTV URL/File: Import EPG from an external XMLTV feed
  • Provider (legacy): Passthrough from your IPTV provider — lower quality; migrate to SD or XMLTV when possible
  • PPV Events: Auto-managed source synced during PPV channel enrichment (read-only)

About Channel Mapping

EPG mappings link your IPTV channels to program guide data. Use the Match Rules tab to configure automatic matching based on channel names, callsigns, tags, and more.

EPG Match Rules

Define how channels are matched to EPG data. Rules run in priority order. Use exclusion patterns to prevent specific channels (like PPV events) from being matched.

Match Rule Types
  • Provider ID: Use provider-assigned EPG IDs
  • Callsign: Match by broadcast callsign (e.g., KABC, WNBC)
  • FCC Lookup: Look up callsigns from FCC database
  • Exact/Fuzzy Name: Match on channel names
  • Network Fallback: Use generic network EPG
