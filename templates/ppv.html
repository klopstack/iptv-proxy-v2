About Enrichment

What is enrichment?

PPV enrichment matches your channel names against TheSportsDB's extensive database of sports events. This adds rich metadata to your PPV channels for better organization and filtering.

Data added:

  • Sport type (Football, Basketball, etc.)
  • Team/league information
  • Venue and location
  • Event status and timing
  • Broadcast details

Note: Enrichment works best with channel names containing event/team information (e.g., "UFC 293: Silva vs Adesanya").

TheSportsDB

TheSportsDB is a free, community-driven sports database containing information about athletes, teams, events, and more.

PPV Event Filtering

Use filters to include or exclude PPV channels based on categories, names, or custom patterns.

Filtering Tips:
  • Go to Filters to create account-specific filter rules
  • Use category filters to include/exclude PPV categories by name
  • Use regex patterns to match specific event names or sports types
  • Combine with visibility settings for complete control
  • Use tag-based filters on playlists after enrichment to filter by event type
Quick Start
  1. Go to Filters page
  2. Select your IPTV account
  3. Create a new filter with type category or channel_name
  4. Set value to PPV category name (e.g., "PPV Events")
  5. Choose Include to show only those categories, or Exclude to hide them
Note: Filters work in combination with visibility settings. For example, if visibility is "Hide Inactive PPV" and a filter excludes a category, only upcoming/active events in non-excluded categories will show.

About Queue

What is the enrichment queue?

The enrichment queue manages PPV channels waiting to be matched with event data from TheSportsDB. Channels are automatically queued during account syncs, but you can manually queue or reprocess them here.

Queue States:

  • Queued: Waiting to be processed
  • Processing: Currently being matched
  • Matched: Successfully enriched
  • No Match: Event not found in database
  • Error: Processing failed
